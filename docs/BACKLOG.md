## 하지 않기로 한 것

- 캐릭터 선택창 (사용자: 지금 캐릭터로 유지)
- 낚는 어종(청새치·돛새치·만새기·바리 등)의 실사 모델: Fab에 없음 → 코드 모델 유지

## 참고

- 개인용 0원 에셋은 `PERSONAL=1 node tools/fab/fabget.mjs …` 로 받는다. 등급 메뉴에서 Personal 이 Free 로 표시될 때만 고르며 결제 단계는 없다.
- Fab 검색 결과의 `p=` 는 가격이 아니라 폴리곤 수다. 가격은 목록 상세(`/i/listings/<uid>` 의 licenses)로 확인한다.
